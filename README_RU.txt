ETS2 TWITCH BOT — программа с окном
====================================

Зрители покупают награды за баллы канала Twitch (или донатят через DonationAlerts) —
в Euro Truck Simulator 2 нажимаются клавиши: руль, тормоз, газ, гудок, фары и т.д.
Всё настраивается прямо в окне программы, ничего редактировать вручную не нужно.

УСТАНОВКА
---------
1. Запусти ETS2_Twitch_Bot_Setup.exe, нажми «Установить».
   Программа встанет в папку пользователя, на рабочем столе и в «Пуск» появится ярлык.
   Права администратора не нужны. Больше ничего устанавливать не надо.
2. Запускай программу ярлыком «ETS2 Twitch Bot».
3. Удаление: Параметры Windows → Приложения → «ETS2 Twitch Bot» → Удалить
   (или значок в «Пуск» → правый клик → Удалить). Можно сохранить свои настройки.
4. Обновление: просто запусти новый Setup.exe поверх — настройки сохранятся.

Windows SmartScreen может написать «Неизвестный издатель» (файл не подписан):
«Подробнее» → «Выполнить в любом случае».

ПЕРВЫЙ ЗАПУСК (5 минут)
-----------------------
1. Запусти программу ярлыком. Настройки (settings.json и др.) хранятся в её папке установки
   (кнопка «Открыть папку программы» во вкладке «Настройки»).
2. Вкладка «Настройки» → блок Twitch:
   а) Нажми «Открыть консоль Twitch», войди в аккаунт, «Зарегистрировать приложение».
   б) Название любое. В «OAuth Redirect URLs» впиши:  http://localhost:3000
   в) Категория «Application Integration», тип клиента «Confidential». Сохрани.
   г) Скопируй «Client ID» и нажми «Новый секрет» — скопируй «Client Secret».
   д) Вставь оба значения в программу. Redirect URL в программе должен совпадать.
3. Вкладка «Главная» → «Создать награды на Twitch». Откроется браузер: разреши доступ.
   Программа создаст награды на твоём канале (нужен статус партнёра или аффилиата).
   ВАЖНО: награды должны создаваться именно программой — только такие она может
   отмечать выполненными и возвращать за них баллы.
4. «Запустить» → переключись в игру. Готово!

ДОНАТЫ (по желанию)
-------------------
1. donationalerts.com → Разработчикам → «Создать приложение».
   Redirect URI:  http://localhost:3001   Права: oauth-user-show, oauth-donation-subscribe.
2. Вкладка «Настройки» → DonationAlerts: впиши Client ID и Secret.
3. Вкладка «Донаты» → включи переключатель «Донаты включены».
4. Правила проверяются сверху вниз, срабатывает первое подходящее. Можно менять ключевые
   слова, суммы, «каждые N ₽ = одно повторение», порядок (кнопки «Выше/Ниже»).
5. Кнопка «Какое правило сработает?» покажет результат без настоящего доната.

ПОДСКАЗКИ ПО ДОНАТАМ В OBS
--------------------------
Программа сама показывает зрителям, что можно сделать за донат: красивый список правил
(сумма, слова для сообщения, подсказка) с листанием страниц.
1. Вкладка «Настройки» → «Оверлей для OBS» → кнопка «Копировать ссылку».
2. В OBS: Источники → ＋ → «Браузер» → вставь ссылку, ширина 700, высота 650. Фон прозрачный.
3. Что показывать: вкладка «Донаты» → правило → «Показывать в оверлее» и поле «Подсказка».
   Если подсказка пустая, берётся описание награды.
4. Правишь правила — страница в OBS обновляется сама (до 4 секунд).
Работает, пока открыта программа (запускать бота для этого не нужно).
Если порт занят — смени его в настройках оверлея (по умолчанию 3002).

НАГРАДЫ И ДЕЙСТВИЯ
------------------
Вкладка «Награды»: слева список, справа редактор. Действие пишется простыми строками:
   hold steer_left 1.5      зажать клавишу на 1.5 секунды
   press horn 3 0.25        нажать 3 раза с паузой 0.25 сек
   wait 0.5                 пауза
   repeat 4 ... end         повторить блок 4 раза (строкой end блок закрывается)
   # текст                  комментарий
Имена клавиш (steer_left, brake, horn…) и сами клавиши (a, w, space, f5) настраиваются
во вкладке «Настройки» → «Клавиши управления» — впиши те, что назначены в твоей ETS2.
Кнопка «Проверить» выполнит действие через 3 секунды (успей переключиться в игру).
Изменил название/цену награды — нажми «Создать награды на Twitch» ещё раз (новые
создаются, существующие пропускаются).

ПОЛЕЗНОЕ
--------
* «Аварийный стоп» — сразу отпускает все клавиши и очищает очередь (баллы возвращаются).
* «Тестовый режим» (Настройки) — клавиши не жмутся, всё только пишется в «Журнал».
  Удобно проверить настройку, не запуская игру.
* Действия выполняются по одному, по очереди. Если окно игры не в фокусе, награда
  отменяется и баллы возвращаются (донаты ждут окно игры 30 секунд).
* Если игра запущена от администратора — перезапусти программу кнопкой
  «Перезапустить от администратора» (Настройки → Сервис), иначе Windows не даст жать клавиши.
* Файл last_action.txt можно подключить в OBS как текст — там название последнего действия.
* Закрытие в трей: Настройки → «Сворачивать в трей».

БЕЗОПАСНОСТЬ
------------
settings.json, twitch_tokens.json, da_tokens.json содержат твои секреты и токены.
Никому их не показывай и не отправляй. Если отправляешь программу другу — отправляй
только Setup.exe (без этих файлов): у каждого будут свои ключи.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
Открой вкладку «Журнал» — там написано, что именно не получилось. Тот же текст сохраняется
в ets2bot.log рядом с программой.


=== Версия 1.5.0: что нового ===

* Горячая клавиша «Паника» (по умолчанию Ctrl+Alt+X; меняется на вкладке «Настройки»):
  мгновенно отпускает все клавиши и очищает очередь, даже если активна игра.
* Пауза между наградами (по умолчанию 2 сек), чтобы награды не шли встык.
* Чат: бот может писать «кто что запустил» и отвечать на !награды списком наград с ценами.
  Сообщения уходят от имени твоего аккаунта Twitch.
* События Twitch: награда (из списка наград) за новую подписку, за биты (от N) и за рейд (от N зрителей).
* Оверлеи для OBS: алерт «кто что запустил» с таймером (/alerts) и топ мучителей (/top, ?mode=all — за всё время).
  Ссылки на вкладке «Настройки», блок «Оверлей для OBS».
* Сохранение и загрузка настроек в файл (вкладка «Настройки», блок «Сервис»).
* После обновления программа один раз попросит войти в Twitch заново: нужны новые права (чат, подписки, биты).

* Мелодии гудком (награды «Гудок: …»): Кукарача, Имперский марш, Jingle Bells, С днём рождения, тук-тук.
  У машины один тон гудка, поэтому мелодию можно узнать только по ритму. Ритм меняется в шагах награды
  (hold horn — гудеть, wait — пауза).

* Рулетка: награда «Рулетка» запускает случайную награду из списка (галочка «Может выпасть в рулетке» у каждой награды).
  Работает и через донат (ключевое слово «рулетка»).
* Голосование чата: чат голосует !1 !2 !3, побеждает большинство. Запуск кнопкой или автоматически каждые N минут.
  Оверлей голосования: ссылка в настройках. Нужен перезапуск бота после включения.
* Дорожающие награды: у награды поле «Дорожает после каждой покупки на» (баллы). Цена на Twitch растёт после покупки
  и каждые N минут падает на один шаг; при остановке бота возвращается к обычной.
* Общая копилка: награда «Копилка» кладёт свою цену в общий банк; когда набрана цель — запускается «мега-хаос».
  Оверлей копилки: ссылка в настройках.
* Чёрный список: награды таких зрителей отменяются с возвратом баллов, донаты и события не запускают действий.
* Отчёт за стрим: при остановке бота сохраняется в папку reports (html). Кнопка «Отчёт за стрим сейчас» в настройках.

* Мастер настройки: при первом запуске (когда не заполнен Client ID Twitch) открывается пошаговый мастер:
  приложение Twitch → создание наград → DonationAlerts (необязательно) → клавиши игры → проверка гудка.
  Открыть снова: «Настройки» → «Сервис» → «Мастер настройки».
