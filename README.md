# ETS2 Twitch Bot

Программа для стримеров на Euro Truck Simulator 2: зрители за баллы канала Twitch и донаты (DonationAlerts) мешают водить. Windows, .NET 8, WPF.

## Возможности
- Награды за баллы Twitch и правила для донатов (руль, тормоз, газ, гудок, камера, лупа и другие)
- Мини-язык действий: `hold`, `press`, `wait`, `scroll`, `repeat … end`
- Рулетка, голосование чата (`!1 !2 !3`), общая копилка, дорожающие награды
- Гудок-мелодии, реакции на подписки, биты и рейды
- Оверлеи для OBS: подсказки по донатам, алерты, топ, голосование, копилка
- Чат-бот (`!награды`), чёрный список, пауза между наградами, горячая клавиша «Паника»
- Отчёт после стрима, мастер первой настройки, экспорт и импорт настроек

## Сборка
Нужен .NET 8 SDK.

```
dotnet publish ETS2TwitchBot.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Автопроверки: `ETS2TwitchBot.exe --selftest`, результат в `selftest_log.txt`.

Один и тот же exe — программа и установщик (если в имени файла есть `setup`).

## Важно
Ключи Twitch и DonationAlerts хранятся только локально в `settings.json` и `twitch_tokens.json`. Эти файлы в `.gitignore`, их нельзя публиковать.
